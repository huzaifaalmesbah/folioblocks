# Putting the theme on a site

Tell the person these steps, adapted to where their site is. Don't unzip the zip: WordPress takes it as it is.

## Install

- **Any WordPress site**: WP Admin → Appearance → Themes → Add New Theme → Upload Theme → choose the zip → Install Now → Activate.
- **WordPress.com**: needs the Personal plan or higher to upload themes. Appearance → Themes → Add Theme → Upload Theme → Install Now → Activate.
- **On their computer first**: WordPress Studio (free, https://wordpress.studio/), then the same upload steps in its WP Admin.

## Set up the pages (once)

1. Pages → Add New Page: create **Home**, **About**, **Blog** and **Contact** (a title is enough).
2. About: Settings sidebar → Template → **About**. Contact: Template → **Contact**.
3. Settings → Reading → "A static page": Homepage = Home, Posts page = Blog. Save.

## After that

- **Change anything**: Appearance → Editor (Styles for colours and fonts, Navigation for the menu, Templates and Patterns for sections).
- **New page**: Pages → Add New Page; WordPress offers the theme's page designs to start from.
- **Post**: Posts → Add New Post → write, set a featured image → Publish. It shows on the Blog page and in "Latest posts".
- **Update the theme later**: rebuild, upload the new zip the same way, choose "Replace active with uploaded". Pages, posts and Site Editor changes stay.
